# رها — مرکز جامع و جامعهٔ حمایتی وسواس

«رها» یک PWA فارسی، راست‌به‌چپ و نصب‌شونده است که برای پاسخ سالم‌تر به OCD، نشخوار، وسواس شرعی، موضوعات زنان و فشار وسواس بر رابطه و خانواده طراحی شده است.

این پروژه مستقل است و هیچ ارتباط فنی یا مخزنی با پروژه‌های ERP سازمانی ندارد. در متن درمان، ERP به معنای **Exposure and Response Prevention** یا «مواجهه و جلوگیری از پاسخ» است.

**نسخهٔ زنده و نصب‌شونده:** [yadrouj.github.io/Vasvas](https://yadrouj.github.io/Vasvas/)

## الان چه چیزهایی کار می‌کند؟

- شروع امن و رضایت آگاهانه
- حالت شخصی و حالت همراه
- کمک فوری سه‌مرحله‌ای بدون اطمینان‌دادن
- راهنمای گفت‌وگویی «از رها بپرس» با قاعدهٔ ثابت، منبع فقهی و توقف پاسخ‌های تکراری
- ثبت شدت میل و پاسخ متفاوت روی همان دستگاه
- تمرین تنفس ۴–۶ با هشدار دربارهٔ تبدیل‌شدن به آیین اجباری
- محتوای آموزشی درباره چرخه وسواس، نشخوار و نقش خانواده
- دایره‌المعارف جست‌وجوشونده با ۱۹ موضوع: آلودگی، وارسی، افکار ناخواسته، رابطه، زنان، بارداری/پس‌اززایمان و اختلالات مرتبط
- پرونده‌های ویژهٔ زن و شوهر، صمیمیت، چرخهٔ قاعدگی و یائسگی با مرزهای پزشکی و رضایت
- بخش شرعی با منبع رسمی دفتر آیت‌الله سیستانی
- بخش دارو، پروپرانولول، آرام‌بخش‌ها و گیاهان با درجهٔ شواهد و هشدار ایمنی
- ویدئوها، پادکست‌ها و منابع بالینی معتبر
- تنظیم اعلان مرورگر و اعلان آزمایشی
- خروجی JSON از داده‌های شخصی
- طراحی و شبیه‌سازی تجربهٔ مکث پیش از گوشی و ساعت هوشمند
- جامعهٔ حمایتی با فید، دسته‌بندی، پیش‌نویس موضوع، پاسخ، هم‌قدمی، گزارش و قوانین ضد اطمینان‌خواهی
- محافظ متنی برای خطر فوری، درخواست دوز دارو و فتوای موردی
- اتصال به [تالار عمومی GitHub Discussions](https://github.com/Yadrouj/Vasvas/discussions) برای موضوع‌های زنده
- اجرای آفلاین پایه با Service Worker

فید داخل اپ فعلاً محلی است و دادهٔ آن بین کاربران همگام نمی‌شود؛ تالار عمومی از GitHub باز می‌شود. پیام بین دو گوشی، مسدودکردن واقعی اپ‌های دیگر و خواندن حسگر ساعت نیز در این نسخه نمایشی‌اند. این قابلیت‌ها به backend امن، مدیریت انسانی و اپ بومی نیاز دارند و رابط این محدودیت را اعلام می‌کند.

## اصول محصول

1. **رضایت، نه اجبار:** همسر یا همراه حق ندارد بدون رضایت صاحب حساب، گوشی، پیام یا داده سلامت او را کنترل کند.
2. **همدلی بدون اطمینان‌دهی:** اپ درباره پاکی، درست‌بودن حرف یا بی‌خطر بودن، پاسخ قطعی تکراری نمی‌دهد.
3. **ابزار، نه درمانگر:** تشخیص، طراحی تمرین مواجهه و تجویز دارو بیرون از اپ و با متخصص انجام می‌شود.
4. **کمترین داده:** پیش‌فرض محلی است. هر نوع اشتراک، مجوز مستقل و قابل لغو دارد.
5. **عدم تشخیص از روی ساعت:** ضربان یا حرکت دست فقط می‌تواند پیشنهاد یک check-in بدهد، نه اینکه «حمله وسواس» را تشخیص دهد.
6. **جلوگیری از اجبار دیجیتال:** تعداد یادآورها محدود و قابل خاموش‌کردن است؛ خواندن مکرر کارت‌ها به‌عنوان اطمینان‌خواهی هشدار داده می‌شود.

## مسیر نسخهٔ واقعی موبایل و ساعت

جزئیات در [ARCHITECTURE.md](./ARCHITECTURE.md) آمده است. خلاصه:

- اشتراک پیام و موفقیت‌ها: backend با هویت ناشناس، کد جفت‌سازی یک‌بارمصرف، scopeهای جدا و لغو فوری
- iOS: SwiftUI، Screen Time API (`FamilyControls`, `ManagedSettings`, `DeviceActivity`)، HealthKit و watchOS
- Android: Kotlin/Compose، اعلان بومی، Health Connect و Wear OS Health Services؛ هرگونه Accessibility فقط با افشای روشن و رضایت
- پردازش سیگنال روی دستگاه، cooldown و پرسش خنثی «یک مکث می‌خواهی؟»

[RESEARCH_FA.md](./RESEARCH_FA.md) جمع‌بندی پژوهش، منابع، محدودیت‌ها و منطق تصمیم‌های محصول است. این محتوا نسخهٔ پزشکی یا فتوا نیست.

## ایمنی جامعه

جامعه برای حمایت از «پاسخ درمان‌ساز» طراحی شده، نه جواب‌دادن به محتوای وسواس. دوز و نسخهٔ دارو، فتوای شخصی، تضمین پاکی/بی‌خطری/عشق، جزئیات گرافیکی و پاسخ به بحران در تالار مجاز نیست. [راهنمای کامل جامعه](./COMMUNITY_GUIDELINES_FA.md) پیش از مشارکت باید خوانده شود. نسخهٔ چندکاربرهٔ مستقل باید پیش از انتشار عمومی، مدیریت انسانی آموزش‌دیده، صف گزارش، سیاست کودک و مسیر بحران داشته باشد.

## وضعیت

نسخه ۰.۲ یک MVP پژوهش‌محور است و برای درمان واقعی باید توسط روان‌شناس/روان‌پزشک آشنا با OCD، متخصص سلامت زنان، کارشناس حریم خصوصی و مرجع دینی منتخب کاربر بازبینی شود.
